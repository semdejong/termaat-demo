# URL-mapping

Bestaande paden en het pad in dit concept. De website van Schildersbedrijf A.F. ter Maat zelf blijft ongewijzigd. Redirects staan in `next.config.ts` en lezen `lib/migration.ts`.

| Bestaand pad | Pad in dit concept |
| --- | --- |
| `/` | `/` |
| `/index.html` | `/` |
| `/index.php` | `/` |
| `/schilderwerk.html` | `/schilderwerk` |
| `/wandafwerking.html` | `/wandafwerking` |
| `/beglazing.html` | `/beglazing` |
| `/referenties.html` | `/referenties` |
| `/contact.html` | `/contact` |

`/over-ons` is een pagina in dit concept. Daarvoor is geen overeenkomstig `.html`-pad vastgesteld.
